# Código del proyecto

Los pasos de instalación y ejecución están en el [README principal](../README.md).

- `proyecto_mlp.py`: carga los datos, entrena y evalúa las MLP.
- `proyecto_final.ipynb`: notebook que reutiliza el script.
- `requirements.txt`: dependencias de Python.
- `resultados/`: métricas, gráficas y dataset reducido.
- `resultados_preprocesamiento/`: auditoría inicial de los datos.
- `docu-reporte/`: explicaciones de los conceptos y métodos utilizados.
